# Forest Guardian · Chiang Mai

A responsive conservation operations dashboard built with Next.js, React, TypeScript, and CSS. Monitoring figures and the forest map are illustrative sample content; no live sensor service is connected.

## Run locally

```sh
pnpm install
pnpm dev
```

The development server runs at `http://localhost:3000`. Create and validate a production build with `pnpm build`, then serve it with `pnpm start`.

## Pages

- Overview
- Digital Twin
- Satellite
- IoT Sensors
- Camera Traps
- Acoustic AI
- Drone Fleet
- Alerts
- Wildlife
- Analytics
- Settings

## Deploy

Import the repository into Vercel using the default Next.js settings. The project has no required environment variables.
